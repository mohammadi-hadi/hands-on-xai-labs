## Exercise 10.1: Find the steering threshold *(warm-up)*

**Goal.** The lab steers with the "San + city" feature f20677 at two alphas: 20 lifts p(' San') from 0.022 to 0.077 (rank 3 to top-1); 80 overshoots into "city of Diego" (p(' Diego') 0.298, p(' San') collapsing to 0.005). Map the transition between nudge and bulldozer.

**Steps.**
1. In the steering cell ("I grew up in the city of"), sweep `alpha` over `[0, 10, 20, 30, 40, 50, 60, 70, 80]`.
2. At each alpha record p(' San'), p(' Diego'), p(' Francisco'), and the top-1 token.
3. Plot the three probabilities vs alpha; mark where top-1 changes and where p(' San') peaks then collapses.

**Hint.** The steering hook adds `alpha * W_dec[20677]` at all non-BOS positions; only the scalar changes per run, and each run is one forward pass, so the whole sweep is seconds on CPU.

**Solution sketch.** Wrap the existing hooked forward in a loop, collect a small dataframe, plot. Anchors: alpha 20 and 80 from the ledger. The intermediate shape is unledgered. Record where the "acts as if the previous token already was San" regime begins and compare against the chapter's two endpoints. Deliverable: one number, the largest alpha that still *increases* p(' San'), as your working definition of this feature's safe steering range on this prompt.

## Exercise 10.2: Are the induction heads robust to the scan's design? *(core)*

**Goal.** The induction scan (4 sequences of 50 random tokens repeated twice) finds a sharp top-5: L5H5 0.945, L6H9 0.921, L7H10 0.911, L5H1 0.902, L7H2 0.853, with most of the other 139 heads < 0.1. Test whether that set is an artifact of sequence length or token range.

**Steps.**
1. In the induction cell, vary the repeated-block length: 10, 25, 50, 100 tokens (keep 4 sequences, BOS-prefixed).
2. Separately, vary the random-token id range (default 1000–20000): try 20000–40000.
3. For each condition, record the top-5 heads and their scores; check set overlap with the default run.

**Hint.** The score is mean attention from second-copy tokens to the token *after* their first occurrence; the indexing helper already handles arbitrary lengths. Watch short blocks especially: with 10 tokens, positional heads can masquerade as induction heads.

**Solution sketch.** Two loops around the existing scan, a set-comparison print. The default-condition scores should reproduce the ledger exactly (deterministic CPU). Other conditions are unledgered; record what you find. Expected teaching point: a genuinely mechanistic label like "induction head" should be stable across stimulus variants, and instability at short lengths shows why the scan uses 50-token blocks.

## Exercise 10.3: Is the top SAE feature always bookkeeping? *(stretch)*

**Goal.** The feature dashboard's honest headline: on 200 tweets, the #1 feature by max activation (f9303, act 76.4) fires on runs of trailing whitespace (bookkeeping, not meaning) while the semantically crisp f20677 hides mid-pack. Test the hypothesis this invites: formatting features dominate *any* corpus's top slots, so max-activation ranking is the wrong lens.

**Steps.**
1. In the dashboard cell (full mode; the SAE must load), swap the tweet corpus for ~200 texts of a visibly different register: e.g. the notebook's GSM8K-style arithmetic prompts, or paragraphs from any plain-text file you have.
2. Rebuild the top-8-by-max-activation table; classify each top feature by eye (using top exemplar tokens + decoder-lens boosts) as formatting/fragment vs semantic.
3. Re-rank by a different statistic, activation *frequency* (fraction of tokens where the feature is active), and compare the two top-8 lists.

**Hint.** Keep BOS/pad masking as in the notebook, and reuse the decoder-lens helper for interpretation. L0 on the probe sentences was 44.7–59.9 active features per token; frequency ranking will surface a very different population than max ranking.

**Solution sketch.** Change the corpus list, rerun two ranking cells (~10 lines new code for the frequency statistic). Unledgered beyond the tweet-corpus run; record what you find and compare against the chapter's dashboard. Whatever the outcome, write one sentence on which ranking you would show a stakeholder, knowing the ledger kept the whitespace feature as bar #1 precisely because curating it away misrepresents raw SAE output.
